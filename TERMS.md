# Terms of Service

This is a personal tool that Rob Fuller built to export his own Oura Ring data. It is not a public service and has no other users.

The tool connects to the Oura API only with Rob's own Oura account and only after he has authorised it. It reads his data and saves a copy on his local computer.

The software is provided as is, without warranty of any kind. Anyone who copies the code is responsible for their own use of it and must follow the Oura API Agreement.

Access can be revoked at any time from the Oura account settings.

Questions can be raised as an issue on this repository.
