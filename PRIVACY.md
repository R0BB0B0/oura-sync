# Privacy Policy

This is a personal tool that Rob Fuller built to export his own Oura Ring data. It has no other users and collects no data about anyone else.

**What it accesses:** Rob's Oura data (sleep, readiness, activity, stress, SpO2, heart rate, workouts and tags) through the Oura API, using the permissions he granted.

**Where it is stored:** only in a local database and CSV files on Rob's own computer. Access tokens are also kept locally. Nothing is uploaded to this repository or any other server.

**Sharing:** the data is never shared, sold or passed to third parties.

**Revoking access:** access can be revoked at any time from the Oura account settings. Deleting the local files removes the stored copy.

Questions can be raised as an issue on this repository.
